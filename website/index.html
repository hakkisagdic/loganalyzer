Bizigo LogAnalyzer

GitHub Repository

Plugin-based Log Analysis Platform

Multi-format, multi-language log analysis with agentic root cause analysis. Built for network and infrastructure device logs.

🔌 Plugin Architecture

Extensible parser engine supporting multiple log formats. Add vendor-specific parsers via the catalog system.

📊 Real-time Ingest Pipeline

High-throughput ingestion with normalization, dispatching, and raw archival. Sidecar-based collection.

🔍 Advanced Search & Query

Powered by ClickHouse for fast analytical queries across billions of log entries with full-text search.

🚨 Alerting & Detection

Sigma rule support, correlation engine, and notification channels for proactive incident detection.

🖥️ Modern Web UI

Next.js dashboard with OpenAPI-generated type-safe API client, dark/light mode, and responsive design.

🔐 Enterprise Security

Keycloak-based authentication, JWT validation, multi-tenant isolation, and audit trail.

Quick Start

# Clone the repository
git clone https://github.com/hakkisagdic/loganalyzer.git
cd loganalyzer

# Set up git hooks
git config core.hooksPath .githooks

# Start development environment
cd deploy && cp .env.example .env && docker compose up -d --wait && cd ..

# Build and test
dotnet build
dotnet test tests/Bizigo.UnitTests

# Run the API
dotnet run --project src/Bizigo.Api

# Run the UI (separate terminal)
cd ui && cp .env.example .env.local && npm install && npm run dev
